# The changes to Julia

The inventory of the [compiler reference](../reference/compiler.md): each commit the design adds to Julia v1.13.2, with what it does, its kind and the reference section it builds. For core developers.

- **Where this page and the reference disagree** on what is intended, the reference wins. This page says what is built.
- **The heads** are in [the state](../state.md#today).
- **A row names the decision, the open issue or the experiment it serves** by its ID. The decisions are in [the decision log](../record/decisions.md); how each commit was checked is in [the build notes](../record/build-notes/julia-stack.md).

<a id="7-the-unified-build-branch-unified"></a>
## 1. The line

- **Branch `next`** of the julia repository, worktree `julia-next/`: Julia v1.13.2 (`45b6d15e34`) with the commits below. No rebase on a later Julia is planned.
- **A stack of self-contained commits.** First the changes that are useful without traits, one commit each, each building on v1.13.2 with only the commits below it. Then the type system's sets and memberships, then the facts mode.
- **The kinds:** *general*, useful without traits and facts ([compiler §11](../reference/compiler.md#11-changes-useful-without-traits)); *traits*, the type system's sets and memberships; *facts*, the facts mode; *compiler* and *runtime*, a fix in that part; *merge*.
- **The control** is vanilla v1.13.2, worktree `julia-vanilla/`, built on the same host.
- **Building:** `tools-local/build.sh julia-next` ([setup](../setup.md#build-julia)).
- **What is not built as the reference states it** is in the references' Deviations tables. The gates and acceptance cases are in `experiments/implementation/`.
- **The rows to 123** are the stack to the tag `prototype-2026-11` (branch `unified`, 7b374f39ce), the regression control. The rows after it are on `next`.
