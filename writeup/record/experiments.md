# The registry of experiments

The experiments the current claims rest on: what was asked, against what, on which build, what came out, and where the scripts and logs are. It is in the agents' tier ([the record's index](INDEX.md)).

- **The numbers behind a claim** are in [the evidence](../design/evidence.md), each citing its row here.
- **Every experiment ever registered,** with its full row as it was written, is in [the ledger](../../attic/writeup/record/experiments-archive.md). An ID that has no row here is there, with the reason.

## How to use it

- **An experiment has an ID, `E-n`.** IDs are permanent and never reused. A new experiment takes the next free number: **E-541**.
- **The row comes before the run.** It names the goal it gives evidence for (G-n of [the goals](../goals.md)), the question, the baseline, and the result that would change the design or a goal's standing. Commit the row, then run.
- **The baseline is plain Julia or Python:** vanilla v1.13.2, plain code on the build, or Python on the same task. A count on the build alone says "none (a count)"; a gate says "none (a gate)".
- **A comparison with the tag** is a regression control. Its row goes to the last section. No claim cites it.
- **A number says what it measures:** the build (branch and commit), the setting (product, or the test bed), strict mode, the runs, the machine's load. And whether it measures trait code calling plain code, or idiomatic trait code.
- **When it is done,** the outcome gets its key numbers, and the evidence its row, in one commit. The scripts and logs are committed in `experiments/<dir>/`, with a README.
- **When a later run replaces a row,** the old row moves to the ledger with the reason, and the documents that cite it are changed to cite the new one.
- **A criterion crossed by more than its own margin ends the line of work,** until the row's "would change" branch is taken or the row says why not.

**The builds named in the rows.**
- `next`: the head of the changed Julia ([the state](../state.md#today)). `next-s3` was a stage's branch, merged into `next`.
- `unified` at 7b374f39ce, with TraitWorld e11c7cc: the tag `prototype-2026-11`. `unified` at 21c9b33e39 is the freeze of the measurement round (tag `round-2026-11-b`).
- "vanilla": Julia v1.13.2 unchanged (`julia-vanilla`). "stock": a released Julia of the version named.
- "plain code on the build": the same code without traits, run on the changed Julia.
