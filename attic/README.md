# The attic: earlier work, kept for reference

Nothing here is current. The current documents are in [`../writeup/`](../writeup/README.md); how the design came to its shape is in [the project's context](../writeup/record/context.md) and [the design history](../writeup/record/design-history.md); what was not taken, and why, is in [the alternatives](../writeup/design/alternatives.md); what the work taught is in [the lessons](../writeup/design/lessons.md).

## The rule for paths

- **A document moved here keeps its path:** `writeup/plans/x.md` is `attic/writeup/plans/x.md`. A path cited in a session note, a review, a commit message or another repository maps to `attic/<the same path>`.
- **No "Moved" page is left at the old path.**
- **Links inside an archived document are not updated.** Read a relative link from the document's old place: `../reference/traits.md` in an archived plan meant `writeup/reference/traits.md`. Where the target was itself archived, it is here under the same rule.
- **An archived document keeps the terms of its time.** The glossary gives today's.
- **Ledgers:** closed work items, closed issues, superseded decisions, retired deviation rows and the experiments of earlier builds are in [`writeup/record/`](writeup/record/).

## The digest

Each archived plan, review and exploration was read for the documentation clean-up of 2026-11-18 (W-162). The reading's notebook has an entry for each: what it was, what it found, what became of each finding, and what it gave to the lessons and the alternatives: [the harvest notebook](../writeup/record/harvest-2026-11.md). The tables below name the entry for each document.
