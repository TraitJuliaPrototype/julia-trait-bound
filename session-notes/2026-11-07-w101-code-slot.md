## What was built (`unified` 7500630036)

- **The plan first:** `writeup/plans/2026-11-07-w101-the-code-slot.md`; E-283 registered before the run.
- **The record:** at the end of optimization, the compiler lists as `ResultEdges` on the analysis results the callees the code reaches only by `:invoke`s typed by their results. Excluded: inlined, concretely evaluated or constant-propagated anywhere; reached by `invoke` or a match list; not cached. The equivalent-CodeInstance swaps in the JIT and image queues now require the same record, since they compile one CodeInstance's source as another's code.
- **The slot:** codegen's `emit_code_slot`.
  - A private global per call site holds the CodeInstance last called.
  - A call checks the task's world against its range, then calls its specialized entry (or `invoke`, for a boxed call).
  - A miss calls `jl_code_slot_resolve`. A needsparams call already goes through `jl_invoke`, a world-checked lookup.
- **The marks:** `_invalidate_backedges` marks a caller whose only edge to a callee invalidated through its own edges is a result edge.
  - A mark lowers `max_world` and sets a flag.
  - A later invalidation makes the mark final. Images mask the flag.
- **Revalidation:** `revalidate_code_instance`, depth first, in the latest world, committed under `world_counter_lock`. It runs where code is looked up:
  - `jl_compile_method_internal`;
  - a slot's miss;
  - inference's cache miss in `typeinf_edge` (added once the gate showed a facts caller inferred again by its invalidated caller).
