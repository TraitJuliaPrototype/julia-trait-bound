## Pitfalls met tonight

- **A scratch checkout of TraitWorld needs its own depot** (`JULIA_DEPOT_PATH=<scratch>:…`): two checkouts of one package precompile into the same cache directory, which keeps a bounded number of files.
- **Scripts that write a registry row's outcome** must assert the five-cell shape of a registered row (`| where | | |` splits into five): two rows lost their where cell. `experiments/docs-checks/check_tables.py` finds every table row with the wrong number of cells.
- **A closure that captures a type** compiles once per type (E-322's pattern); `experiments/unification/audit/type_closures.jl` lists them from a compile trace.
- **A probe that defines a method and calls it in one top-level statement** reads the old world: use `Base.invokelatest`.
- **The gates' `m3_*` files are not run** (their README); `m3_ambiguity_dominance` pins a rule the references do not have.
